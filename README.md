# dsh-quiz

> 给 [DeepSeek Harness](https://github.com/Phant0Meow) 做的**做题回炉**插件：从你自己的课本/笔记里出题，错题按三阶段回炉，按考点统计正确率。

一句话原则：**无出处，不出题。**

---

## 为什么做这个

大部分「AI 出题」最致命的问题不是题目难，而是**题目没有依据**——模型凭印象编一个考点，你做完还以为自己错了。这个插件把三条规则写进了代码，而不是写进提示词：

1. **每道题绑原文**：题目必须挂在一段真实原文（chunk）上，带书名和页码。
2. **每个给分点可回查**：给分点必须带一句原文原句，且这句必须真的能在原文里找到，找不到直接**拒绝入库**。
3. **长答不冒充机判**：选择题、填空配对机器判；短答、长答由 AI 给逐点证据与建议分，可以改。

---

## 特性

| 能力 | 说明 |
|---|---|
| 资料入库 | Markdown 按小节切段，超长再切，每段保留标题与页码 |
| 四种题型 | MCQ / 填空配对（填代号）/ 短答 / 长答，按 DSE 题型设计 |
| 范围自动选 | 到期复习 40% · 未掌握考点 30% · 最近章节 20% · 混合 10% |
| 错题回炉 | 1 天原题 → 3 天变式 → 14 天混合；变式与混合都过才算掌握 |
| 三档可信度 | `official` / `verified` / `draft`，模拟模式只出前两档 |
| 三条曲线 | 首次正确率、分阶段重做、按考点正确率（口径互不混算） |
| 练习 / 模拟 | 练习可看解析；模拟只给页码，交卷后才开放原文 |
| 面板 | 设置页「测验」一页：库存、曲线、覆盖、资料库 |

## 安装

### 方式一：插件市场

在 DSH 的插件市场里搜 `dsh-quiz` 安装（发布后可用）。

### 方式二：本地 tgz

```bash
# 先打包
npm pack          # 产出 dsh-quiz-0.1.0.tgz
```

然后在 DSH 的插件管理里选择「从文件安装」，选这个 tgz。

> ⚠️ 如果 DSH 版本与 `engines.dsh` 不匹配，安装器会拒绝并回滚。确认版本后再装：
> ```bash
> node -p "require('./package.json').engines.dsh"
> ```

## 快速开始

在任意项目目录里开一个会话，直接说：

```
帮我把这一章导入测验库：《經濟學 中四上》第 1 章
```

（把课本那一页整理成 Markdown 发给我，或直接发图让我转文本。）

然后：

```
出 10 道经济测验题
```

插件会自动挑范围，并先告诉你这次考什么：

> 本次范围：機會成本(4)、稀少性(3)、分工(3)｜来源：《經濟學 中四上》p.1–34｜**跳过**：邊際分析（未覆盖）

答完后：

```
第 3 题我选 B
```

错题会自己排进明天；到期时 `quiz_start` 会优先挑它们。

面板在 **设置 → 测验**，能看三条曲线和覆盖情况。

## 工具一览

| 工具 | 作用 |
|---|---|
| `quiz_import` | 导入 Markdown 资料，切段入库 |
| `quiz_topics` | 列/建考点，看覆盖 |
| `quiz_add_question` | 出题入库（强制校验出处） |
| `quiz_start` | 组卷（范围自动选） |
| `quiz_record` | 记录作答（判分 → 推进排程 → 可信度升级） |
| `quiz_stats` | 三条曲线、错误归因、到期数 |

## 数据存在哪

```
<你的项目目录>/.dsh-quiz/
├── meta.json
├── sources.json    资料清单
├── chunks.json     切好的原文段落
├── topics.json     考点
├── questions.json  题目 + 给分点 + 出处映射
├── attempts.json   每次作答
├── sessions.json   每份卷
└── sources/*.md    你导入的原文（原样保留）
```

全在本地，纯 JSON，可以直接备份或丢进 Git（`.dsh-quiz/` 已在 `.gitignore` 里，看你要不要提交）。

## 设计原则

- **宁可少一道题，不要一道无源题**
- **当天的正确 ≠ 隔日的记忆**：结束页说「答对 / 新增待复习 / 已巩固」，不说「今日掌握」
- **不做连续打卡**：断了会整体放弃，改用「到期」机制
- **不自动扩展题库**：资料没覆盖的考点，明说「未覆盖」

完整设计见 [`docs/设计稿-v2.md`](docs/设计稿-v2.md)，使用手册见 [`docs/使用说明.md`](docs/使用说明.md)。

## 开发

```bash
npm test           # 单元测试（node --test）
node index.js --selftest   # 一条龙自检：导入→出题→组卷→作答→统计
```

自检只写临时目录，不碰真实数据。

---

## 已知限制

- 面板只读：答题在对话里完成，面板只负责看
- 短答/长答的逐点评分依赖调用方（AI）给出，插件只负责阈值判定
- 暂不支持图片直接入库（图先发给 AI 转成 Markdown）
- 尚未支持多选题与排序题
